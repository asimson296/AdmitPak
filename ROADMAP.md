# AdmitPak — Product Roadmap

## ✅ V1 — Done (Sept 2026)
- 8 universities with full data
- Deployment on Render (free tier)
- MongoDB Atlas for persistent data
- Auth (signup / login / logout)
- Track universities + saved list
- Share buttons (WhatsApp / FB / X / Copy)
- Floating feedback button (movable)
- Onboarding tour (Shepherd.js)
- HEC Recognized badge
- Google indexed
- UptimeRobot keeping site awake
- Image optimization (WebP, 90% smaller)

## 🎯 V1.5 — Next 1–2 Months
- [ ] WCAG accessibility pass (alt text, keyboard nav, contrast)
- [ ] Google Analytics integration
- [ ] Email deadline alerts (Resend free tier)
- [ ] Urdu language support (bilingual site)
- [ ] PWA (install on phone as app)
- [ ] Add 10+ more universities (GIKI done, add PIEAS, NED, Bahria, Air Uni, QAU, AKU, KEMU, etc.)

## 🔮 V2 — 3–6 Months
- [ ] Admin approval pipeline (monitor → review → apply)
- [ ] HEC traffic-light system (Green / Yellow / Red)
- [ ] Program-level accreditation (PEC, NCEAC, NBEAC, PMDC)
- [ ] Merit calculator (per-university formulas)
- [ ] Filter by city / discipline / fee range
- [ ] Side-by-side university comparison

## 🚫 V3+ — 6+ Months (After user traction)
- [ ] Conversational AI chatbot (admissions Q&A)
- [ ] AI university matcher (based on marks + preferences)
- [ ] AI merit prediction ("what are my chances at NUST?")
- [ ] Advanced analytics & heatmapping
- [ ] Personalized home feed

## 📌 Guiding Principles
- **Data before features.** No feature ships without the data to make it useful.
- **Free tier only.** Rs. 0 until real earnings.
- **Mobile-first.** Most users are students on Redmi/Infinix.
- **Verified over flashy.** Every claim links to official source.
- **One thing at a time.** Ship small, ship often.
